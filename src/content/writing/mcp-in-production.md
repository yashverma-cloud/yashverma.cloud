Model Context Protocol has gone from a new spec to something nearly half of software companies now run in production.

MCP is the open protocol that lets AI agents connect to the tools and data they need to actually act, not just chat. A recent survey of software company technical leaders found close to half are already running it in production, with developers as the largest group of users, followed closely by data analysts and scientists.

What stood out to me is where it is being used. Beyond code generation, the leading use cases are test generation and coverage, code review and QA automation, and debugging production issues. That last one matters: it means AI agents are getting wired into the same operational loop most of us live in daily, alongside logs, dashboards, and alerts.

The same survey flagged security as the top adoption obstacle, ahead of cost or reliability. That tracks. An agent with access to internal tools and data is a new kind of attack surface, and governance is still catching up to how fast adoption is moving.

Worth watching if you work anywhere near CI/CD, observability, or internal tooling. This is moving from experiment to stack faster than most infrastructure trends do.
